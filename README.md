#  Cheap & Best Men's Salon – Mogappair

A premium, interactive and modern 3D website developed for **Cheap & Best Men's Salon, Mogappair, Chennai**.

The website combines a high-end visual experience with AI-powered features, Google Maps integration, online booking, Firebase backend services, and an interactive Barber Game Simulator.

---

##  Features

###  Premium 3D Website

- Modern premium salon interface
- Responsive design
- Smooth animations and transitions
- Interactive UI components
- Mobile, tablet and desktop support
- Premium dark/modern visual design
- Smooth scrolling and section navigation

### 💈 Salon Information

Displays important salon information including:

- Salon name
- Address
- Phone number
- Opening hours
- Google rating and reviews
- Available services
- Online booking
- Social media links

### ✂️ Salon Services

The website presents services such as:

- Haircut
- Hairstyling
- Hair colouring
- Hair highlighting
- Hair straightening
- Keratin treatments
- Children's cuts
- Shaving
- Shampoo & conditioning
- Make-up services
- Online salon booking

###  Salon Gallery

- High-quality salon photographs
- Video showcase
- Interactive gallery
- Responsive media presentation

###  Barber Game Simulator

An interactive mini-game designed for visitor engagement.

Users can:

- Interact with the virtual hairstyle
- Select barber tools
- Cut hair strands
- Track their STYLE percentage
- Receive interactive feedback
- Restart the game

Available tools include:

-  Scissors
-  Trimmer
-  Shaver

#  AI Features

##  Google Maps Integration

The website can use Google Maps / Maps Grounding for location-related experiences.

Possible features:

- Salon location
- Directions
- Nearby places
- Location information
- Opening-status related queries
- Map-based salon discovery

The website should clearly distinguish between normal Google Maps links and API-based Maps Grounding functionality.

---

## 🎙️ Gemini Live AI Voice Concierge

The website includes an optional AI voice assistant powered by the Gemini Live API.

Customers can interact with the salon assistant using voice.

Example questions:

- "What services do you provide?"
- "What time do you close?"
- "Where is the salon?"
- "How can I book an appointment?"
- "What hair services are available?"

The microphone should only be activated after the user gives permission.

- Profile

- Favourite services

- Feedback
- Customer preferences
